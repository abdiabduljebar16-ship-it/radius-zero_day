2. Brief Explanation of Commands

- cd – Changes the current directory.
- touch – Creates a new empty file.
- cat – Displays the contents of a file.
- wc -l – Counts the number of lines in a file.
- echo – Displays text or writes text to a file.

3. Difference Between > and >>

- > – Overwrites the existing file content.
- > > – Adds content to the end of the file without deleting existing content.

4. File Permissions Observation
   File permissions show who can read (r), write (w), or execute (x) a file. They are assigned to the owner, group, and others.
